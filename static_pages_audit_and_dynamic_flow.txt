1. EXECUTIVE SUMMARY & SYSTEM ARCHITECTURE
================================================================================
The CTS PharmaAssist frontend operates across 5 distinct clinical roles:
  [1] Doctor / Physician
  [2] Pharmacist
  [3] Patient
  [4] Insurance Agent
  [5] System Administrator

Currently, several screens contain:
  - Hardcoded telemetry numbers (e.g., static consultation counts, static adherence percentages)
  - Hardcoded FlChart data points (FlSpot coordinates, static PieChart sections)
  - Disconnected action buttons (buttons that trigger ScaffoldMessenger snackbars without updating AppState/Supabase/Backend)
  - One-way state changes that do not dynamically propagate to other roles

--------------------------------------------------------------------------------
Cross-Role Dynamic Ripple Flow (Target Standard):
--------------------------------------------------------------------------------
  [Doctor Issues e-Rx]
        │
        ▼
  [Insurance PA Verification Engine] ──(If PA Needed)──► [Insurance Agent Friction Portal]
        │                                                           │
        │ (Approved)                                                │ (PA Approved)
        ▼                                                           ▼
  [Pharmacist Dispense Queue] ◄─────────────────────────────────────┘
        │
        ▼
  [Pharmacist Dispenses & Verifies Medication]
        │
        ├──────────────────────────────────────────┐
        ▼                                          ▼
  [Pharmacist Analytics Updated]             [Patient Medicine Cabinet ("My Medicines")]
  (Revenue, inventory, fill rates)                 │
                                                   ▼
                                             [Patient Logs Daily Dose ("Take Dose")]
                                                   │
                                                   ▼
                                             [Adherence Risk Core (PDC Engine)]
                                             (Live PDC score recalculated in real-time)
